🎓 Student Management System
Student Management System is a desktop-based application designed for managing student-related operations such as students, teachers, subjects, fees, and examinations.

🖼️ Current Progress
🔧 This project is still in development. Only the Home Page UI design has been completed so far.

The Home Page displays summary cards for:

Total Students

Total Courses

Total Teachers

Total Fees

📁 Technologies Used
C#

WinForms (.NET Framework)

Visual Studio

📌 Planned Features
⏳ Student Registration

⏳ Teacher Management

⏳ Subject and Course Assignments

⏳ Fee Tracking

⏳ Exam Results
